# ForgeWeaver

ForgeWeaver: A High-Performance, Distributed platform for real-time data aggregation and auto-scaling analytics processing on multi-core processor systems.

ForgeWeaver is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ForgeWeaver.git`
2. `cd ForgeWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
